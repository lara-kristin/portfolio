Reflection

WHAT

I began the discussion viewing autonomy and specialisation as strengths of agent-based systems. Anne’s point about neglected user constraints, and Lana’s concern that fixed roles create bottlenecks, showed me that autonomy can fail when responsibilities are rigid or poorly bounded.

SO WHAT

I realised that robustness depends less on maximising autonomy than on controlling handoffs and preserving constraints. If planning drops a requirement, later evaluation may never detect it. Agents therefore need enough autonomy to challenge poor plans without changing the user’s underlying goals.

NOW WHAT

In future designs, I would record user constraints explicitly, expose subquestions for approval before retrieval, and let agents request replanning within defined limits. I would judge success by whether the system detects weak plans early.

Reflection

WHAT

I argued ACLs add meaning beyond method calls and support looser coupling. Anne showed I had overstated KQML’s performative limitation: communities can add performatives, so the deeper problem is consistent interpretation. Dragos shifted focus to whether receivers have genuine discretion.

SO WHAT

Richer communication is not automatically better. If agents cannot reject, reinterpret or negotiate, ACL semantics add complexity without useful communicative autonomy. Confidence scores improve traceability but do not verify beliefs; accountability requires obligations assessable later.

NOW WHAT

I would keep deterministic exchanges as typed calls. For discretionary interactions, I would record the commitments created so later behaviour can be checked against them. My success criterion would be whether discrepancies between commitments and subsequent agent behaviour are detected.
