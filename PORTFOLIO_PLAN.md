# Design Standards

- Each module begins with a **Module Overview**.
- The middle of each page is determined by the module assessment brief.
- Each module ends with a **Module Reflection**.
- References are included within each activity or artefact where appropriate, rather than as a single bibliography at the end of the page.
- Harvard referencing is used throughout the portfolio.
- Activities are presented in chronological order.
